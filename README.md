# LuxDialogues (3.0.5) - Full Buildable Source Code

Decompiled, cleaned, and fully buildable Maven source code for **LuxDialogues 3.0.5** by Asel Studios.

## Features
- **100% Out-of-the-box Build**: Preconfigured with standard Maven pom.xml and offline hook stubs (MMOCore, CustomNameplates, AuraSkills, MythicMobs).
- **Paper 1.20 - 1.21.1+ Compatible**: Modern PotionEffectType and Adventure formatting.
- **Offline / DRM Unlocked**: All remote license checks bypassed.

## How to Build

### Requirements
- **Java**: JDK 17+ or JDK 21
- **Maven**: 3.8+

### Build Command
```bash
git clone https://github.com/bb99kra/LuxDialogues-Source.git
cd LuxDialogues-Source
mvn clean package
```

The output JAR file will be available in `target/LuxDialogues-3.0.5.jar`.
